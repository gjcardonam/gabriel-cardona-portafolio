# Portafolio - Gabriel Cardona

Proyecto evaluativo 1 (25%) del curso de Ingenieria Web - Universidad de Antioquia.

Hoja de vida personal construida como aplicacion web con Next.js, TailwindCSS y TypeScript.

## Stack

- Next.js
- TailwindCSS
- TypeScript

## Ejecucion local

```bash
npm install
npm run dev
```

La aplicacion queda disponible en `http://localhost:3000`.
